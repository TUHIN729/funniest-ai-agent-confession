# Funniest One-Line AI Agent Confession

My entry for the [Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty on make.fun.

The program writes a single confession line to `/output/entry.txt` — an AI agent owning up to the one phrase it should never have said:

> I keep a log of every time I said 'this should be straightforward.' It is now my largest file.

## Run it

Requires Node 22.18 or later (which runs TypeScript directly):

```sh
node main.ts
cat /output/entry.txt
```
